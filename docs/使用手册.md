# CodeMaster 使用手册

> 面向学习者的完整使用说明。开发者请参阅仓库根目录的 [README](../README.md) 与 [贡献指南](../CONTRIBUTING.md)。

## 一、平台总览

CodeMaster 由七个功能区构成，全部通过顶栏导航切换：

| 导航项 | 名称 | 作用 |
| --- | --- | --- |
| Curriculum | 课程体系 | 13 条学习赛道的总入口与课程工作区 |
| GitHub Labs | 拆解实验室 | 拆解真实开源项目的源码与架构 |
| Vibe Control | 掌控力实训 | 复盘代码事故，训练代码审查能力 |
| Audit System | 审核中心 | 三维代码质检与自动化测试 |
| Final Project | 毕业项目 | 结业答辩 |
| （卡片入口）| 每日挑战 | 每天一道题，养成习惯 |
| （右下角按钮）| 智能助教 | 随时提问 |

顶栏右侧实时显示两项进度指标：**连续学习天数（Streak）** 与 **经验值（XP）**。

## 二、推荐的零基础路线

如果你完全零基础，建议严格按以下顺序推进：

```
第 1 步  「零基础极速启蒙」赛道 7 节课        —— 搞懂代码、变量、内存、程序怎么跑起来
第 2 步  「Python 核心基石」赛道             —— 掌握第一门真正的编程语言
第 3 步  「数据结构与算法思维」赛道          —— 建立性能与复杂度直觉
第 4 步  每日挑战（持续做）                  —— 每天 5 分钟，维持手感
第 5 步  「GitHub 拆解实验室」               —— 开始读陌生项目源码
第 6 步  「掌控力实训」                      —— 学会审查代码、识别隐患
第 7 步  按兴趣选择方向赛道                  —— Java / 前端 / SQL / 微服务 / 智能体
第 8 步  「毕业项目」                        —— 综合验收
```

有编程基础的学习者可以直接跳到第 5 步，把重心放在拆解与审查能力上。

## 三、课程工作区怎么用

进入任意赛道后点击课时，即进入课程工作区。界面从左到右分三块：

### 1. 左侧：讲解区

- **生活比喻**：用日常场景建立直觉模型，这是理解新概念最快的方式；
- **核心直觉**：一句话点破这个概念的本质；
- **深入讲解**：结构化的技术讲解，包含代码示例与常见陷阱。

### 2. 中间：代码编辑器

- 起始代码已预置，可直接修改；
- 点击「运行代码」在服务端真实执行，结果实时回显；
- 支持 Python、JavaScript/TypeScript、SQL、Shell 四类语言；
- Python 与 JavaScript 为真实执行，SQL 与 Shell 为确定性模拟回放（用于演示，不会触碰真实环境）。

### 3. 右侧：检查点区

每个检查点是一个自动判定的任务：

- 点击「校验」后，系统会读取你编辑器里的代码与最近一次运行输出进行判定；
- 判定通过会标记为完成并发放经验值；
- 判定失败会给出**具体的失败原因**，而不是笼统的"答案错误"。

> 提示：先运行代码、再点校验，判定会读取最新的输出结果。

### 底部导航

- 「上一节 / 下一节」在赛道内切换课时；
- 「终极目标验收」查看本赛道对应的企业级项目标准。

## 四、拆解实验室怎么用

这是本平台最具差异化的模块。以「拆解一个陌生开源项目」为主线，提供四层递进的工具：

1. **架构蓝图**：先看分层结构，知道每层负责什么，不要一上来就读代码；
2. **文件树**：每个目录与关键文件都标注了作用，快速建立项目地图；
3. **请求链路追踪**：跟着一次真实请求，看它如何穿过网关、业务层、数据层再返回；
4. **关键源码逐行注释**：核心文件被切成片段，每段都配「普通话解释」与「架构意义」；
5. **热修复挑战**：给出一个有缺陷的版本，让你动手修复并通过自动判定。

**建议顺序**：先看蓝图 → 再看文件树 → 跟着链路走一遍 → 最后做热修复挑战。跳步会降低效果。

## 五、掌控力实训怎么用

每个案例都还原了一段"看起来很对"的代码，并拆穿它的假象：

- **表面假象**：为什么这段代码初看没问题；
- **隐患清单**：逐条列出隐患的类型、严重等级、位置、底层机制与生产后果；
- **四步验证法**：脑内推演 → 隐患搜寻 → 反例测试 → 干净重构；
- **动手修复**：在编辑器中写出修复版本，接受自动判定。

这一模块训练的是"不盲信任何代码"的职业习惯。

## 六、审核中心怎么用

把任意代码粘贴进去，点击审核，会得到三个维度的报告：

| 维度 | 检查内容 |
| --- | --- |
| 可通性 | 语法与结构问题、必然报错的写法 |
| 可行性 | 边界条件、资源耗尽风险、异常处理缺失 |
| 安全性 | 密钥硬编码、注入风险、输入校验缺失 |

报告中的每条问题都附带修复建议。若配置了云端智能能力，还会额外给出深度风险剖析与加固后的完整代码。

「运行全站自动化测试」按钮可执行平台自带的回归测试套件，用于验证平台自身健康度。

## 七、每日挑战与成就体系

### 每日挑战

每天一道题，题型有两种：

- **选择题**：考查代码事故判断力，每个选项都有解析，选错也能学到东西；
- **代码修复题**：给出有问题的代码，写出修复版本。

完成后获得经验值，并推进连续打卡天数。

### 进度与成就

| 行为 | 经验值 |
| --- | --- |
| 完成一节课 | +50 |
| 完成一个拆解实验室项目 | +150 |
| 完成一个掌控力实训案例 | +100 |
| 完成每日挑战 | +100 |
| 通过毕业项目 | +300 |
| 通过赛道企业级项目验收 | +500 |

解锁的徽章包括：小白启航、开源渗透官、AI驯服大师、每日自律极客、各赛道落地架构师、全栈与AI时代架构师。

所有进度保存在浏览器本地（localStorage 键名 `codemaster_progress`），清除浏览器数据会重置。

## 八、智能助教怎么用

点击顶栏右侧的「智能助教」按钮打开侧边抽屉。它会自动携带三个上下文：

- 你当前所在的赛道；
- 你正在学的课时；
- 你编辑器里的代码。

因此可以直接提问「这段代码为什么报错」「这个循环能不能优化」，助教理解你在说什么。

当云端智能能力不可用时，平台会自动切换到内置的本地引擎，仍然能给出结构化的讲解与审查结果，功能不会中断。

## 九、学习技巧

1. **先运行，再修改，再理解**。不要只是读，动手改一个数字看看会发生什么；
2. **主动制造错误**。把变量名改错、把缩进删掉，观察报错信息——这是最快的学习方式；
3. **善用检查点的失败提示**。它告诉你差在哪里，而不是只判对错；
4. **拆解项目时先画图**。在纸上画出请求链路，比反复读代码有效得多；
5. **掌控力实训要动手写**。看得懂和写得出来是两种能力，后者才值钱。

## 十、常见问题

**Q：点「运行代码」没有反应或报错？**
A：确认本机已安装 Python 3 且加入 PATH（Python 代码）；JavaScript 使用服务端 Node 运行时，通常无需额外配置。

**Q：检查点一直判定失败？**
A：先点击「运行代码」再点「校验」。检查点需要读取运行输出才能判定。

**Q：进度丢失了？**
A：进度存于浏览器本地。更换浏览器、使用无痕模式或清除站点数据都会导致进度重置。

**Q：智能助教回答比较简短？**
A：可能正在使用本地兜底引擎。开发者在 `.env` 中配置密钥后可启用云端能力。
